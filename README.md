# IoBioSkipper (`iobioskipper.com`)

Landing page editoriale e immersiva per **IoBioSkipper**, l'attività personale di **Mirko Generoso Vista** (*Skipper, Guida Subacquea & Autore del libro "Io Respiro Mare"*).

## Concept & Direzione Creativa
- **Posizionamento:** Non un charter standard, ma un viaggio raccontato tra il vento e i fondali (sopra la superficie con lo Skipper, sotto la superficie con la Guida Subacquea).
- **Effetto "Immersione" allo Scroll:** Dalla luce della superficie (`#F8F9FA` Bianco Sabbia, `#E0F2FE` Azzurro Acqua Bassa, `#D97706` Oro Solare) fino alla profondità degli abissi (`#0F3D5E` Blu Ottanio, `#061423` Blu Notte Abissale, `#2DD4BF` Turchese Bioluminescente) con indicatore batimetrico laterale (`0.0m` → `-30.0m`).
- **Tipografia:** *Cormorant Garamond* (Serif editoriale) + *Plus Jakarta Sans* (Sans-serif leggibile) + *JetBrains Mono* (Coordinate e quote batimetriche).

## Personalizzazione Rapida
Tutti i testi, gli itinerari, le FAQ, i link Amazon del libro e i contatti (WhatsApp, Instagram, Email) sono raccolti in un unico file:
- `src/config/siteConfig.ts`

## Avvio Locale
```bash
npm install
npm run dev
```
Il server di sviluppo parte su `http://localhost:3005`.
